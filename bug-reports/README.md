# 📁 Bug Reports

В этой папке хранятся баг-репорты для EXE файлов.

## Как использовать

1. Откройте приложение в браузере
2. Перетащите EXE файл (например, `Amiconnect_1_30_3004_Win.exe`) в окно загрузки
3. Приложение автоматически:
   - Декомпилирует PE-структуру файла
   - Проанализирует все секции, импорты, экспорты
   - Найдёт реальные баги в PE-структуре
   - Сгенерирует отчёт
4. Нажмите кнопку **"💾 Скачать баг-репорт"** для сохранения отчёта

## Типы обнаруживаемых багов

### 🔴 Critical
- Неверные сигнатуры (MZ, PE)
- Секции выходят за пределы файла
- Нет секций

### 🟠 High
- W+X секции (уязвимость)
- Отсутствует ASLR/DEP
- EntryPoint вне секций
- Нестандартное выравнивание
- Аномальное количество секций

### 🟡 Medium
- Аномальные timestamps
- Подозрительные импорты (VirtualAlloc, WriteProcessMemory и т.д.)
- Обнаружен оверлей
- Подозрительные строки (URL, пути)
- Обнаружены упаковщики (UPX и др.)

### 🔵 Low
- Нулевой checksum
- Нестандартный ImageBase
- Обрезанные имена секций

### ⚪ Info
- Нестандартные DLL в импортах
- Отсутствующие ресурсы
- Максимальные имена секций

## Формат баг-репорта

Каждый баг содержит:
- **ID** — уникальный идентификатор (BUG-0001)
- **Severity** — критичность (critical/high/medium/low/info)
- **Category** — категория (Security, PE Header, Sections, etc.)
- **Title** — заголовок
- **Description** — описание
- **Details** — технические детали
- **Offset** — смещение в файле (если применимо)
- **Recommendation** — рекомендация по исправлению
