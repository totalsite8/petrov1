[BUG-0001] 🔴 [CRITICAL] NSIS установщик с устаревшей версией
  Категория:    Installer Security
  Описание:     Файл собран с помощью NSIS (Nullsoft Scriptable Install System)
                с признаками устаревшей версии. Обнаружены строки:
                "verifying installer", "unpacking data", "setup1.bin"
  Детали:
    • NSIS версия определена по строкам в оверлее
    • Обнаружена ссылка: http://nsis.sf.net/NSIS_Error
    • Присутствует проверка целостности инсталлятора
    • Формат: "%s\\setup%u.bin" — распаковка в temp-директорию
  Рекомендация: Устаревшие NSIS установщики имеют известные уязвимости
    (DLL hijacking, temp file attacks). Рекомендуется обновить NSIS
    до последней версии (3.x) и включить современные механизмы защиты.

  Описание:     Импортируется AdjustTokenPrivileges из ADVAPI32.dll —

Установщик имеет типичное поведение для NSIS, но содержит несколько
потенциально опасных функций. Рекомендуется:
1. Запустить в виртуальной машине для мониторинга
2. Проверить, какие файлы записываются в систему
3. Проверить, какие ключи реестра модифицируются
4. Обратить внимание на _Nb.exe
