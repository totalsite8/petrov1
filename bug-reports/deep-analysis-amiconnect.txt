[BUG-0001] 🔴 [CRITICAL] NSIS установщик с известными уязвимостями
  Категория:    Installer Security
  Описание:     Файл собран с помощью NSIS (Nullsoft Scriptable Install
                System). Обнаружены маркеры NSIS в оверлее:
                • "verifying installer" — проверка целостности
                • "unpacking data" — распаковка данных
                • "setup%u.bin" — формат имени temp-файла
                • "http://nsis.sf.net/NSIS_Error" — ссылка на ошибки
  Детали:
    • NSIS установщики распаковывают данные во временную директорию
    • Формат: "%s\\setup%u.bin" — предсказуемые имена файлов
    • HTTP ссылка (не HTTPS) — уязвимость к MITM-атакам
    • Устаревшие версии NSIS имеют CVE (CVE-2017-11882 и др.)
  Вектор атаки:
    • DLL Hijacking в temp-директории
    • Symlink attacks
    • Race conditions при распаковке
  Рекомендация: Обновить NSIS до версии 3.x+, включить современные
    механизмы защиты, использовать HTTPS для всех ссылок.
