# BUG-01. Инверсия языка: русский установщик ставит английские ярлыки и английскую лицензию

* **Важность:** средняя (видимая пользователю ошибка локализации, ломает ожидания
  русскоязычных пользователей и вводит в заблуждение при разборе обращений в поддержку)
* **Компонент:** скрипт установщика, `.onInit` + секция 2 «Start menu shortcut» +
  функция выбора лицензии
* **Инструкции:** 2292–2293 (`.onInit`), 1690–1701 (секция 2), 1705–1708 (лицензия)

## Суть

В `.onInit` язык определяется корректно, но признак языка ($Var61) используется
в дальнейшем с **перевёрнутым условием**, из-за чего ветки «русский/английский»
выполняются наоборот.

`.onInit`:

```
2292  IntCmp $LANGUAGE 1049 0 label_2332 label_2332   ; 1049 = русский
2293  IntOp  $Var61 25 + 0                            ; русская ветка → $Var61 = 25
...   StrCpy $Var55 "© $\"АМИКОН$\", 2026"            ; русские строки интерфейса
2332  IntOp  $Var61 9  + 0                            ; английская ветка → $Var61 = 9
2333  StrCpy $Var55 "© $\"AMICON$\", 2026"            ; английские строки интерфейса
```

Секция 2 (ярлыки в меню «Пуск»):

```
1690  IntCmp $Var61 25 0 label_1697 label_1697        ; «== 25» (русский) → прыжок на 1697
1691  CreateDirectory  "$Var98\АМИКОН\Амиконнект"      ; ← русские ярлыки (сюда попадает EN)
1692  CreateShortCut   "...\Амиконнект.lnk" -> "$INSTDIR\amiconnect.exe" args="visible"
...
1696  Goto label_1702
1697  CreateDirectory  "$Var98\AMICON\Amiconnect"      ; ← английские ярлыки (сюда попадает RU)
1698  CreateShortCut   "...\Amiconnect.lnk" -> "$INSTDIR\amiconnect.exe" args="visible"
1699  CreateShortCut   "...\UnInstall Amiconnect.lnk" -> "$INSTDIR\amiconnect-uninst.exe"
```

То же самое при выборе текста лицензии:

```
1705  IntCmp $Var61 25 0 label_1708 label_1708        ; «== 25» (русский) → 1708
1706  File "License.txt"   ; data +0x1B08BA7 size=29918   ← русский текст (см. ниже)
1708  File "License.txt"   ; data +0x1B1008D size=29638   ← английский текст
```

Файлы, вложенные в эти две инструкции, уже различаются по языку — проверено
разбором содержимого (`../extracted/payload/`):

| Инструкция | Смещение/размер | Первая строка файла | Язык |
|---|---|---|---|
| 1706 | `+0x1B08BA7`, 29 918 Б | `ЛИЦЕНЗИОННОЕ СОГЛАШЕНИЕ (EULA) 1. Общие положения…` | русский |
| 1708 | `+0x1B1008D`, 29 638 Б | `LICENSE AGREEMENT (EULA) 1. General Provisions…` | английский |

## Итог для пользователя

* установка с русским языком → в меню «Пуск» появляется папка
  `AMICON\Amiconnect` с ярлыками `Amiconnect.lnk`, `UnInstall Amiconnect.lnk`,
  `License Agreement.lnk`, `Amiconnect Manual.lnk`, а в `$INSTDIR\License.txt`
  (и по ярлыку лицензии) лежит **английский** текст EULA;
* установка с английским языком → папка `АМИКОН\Амиконнект` с ярлыками
  `Амиконнект.lnk`, `Удалить Амиконнект.lnk`, `Лицензионное соглашение…`, и
  **русский** текст EULA.

Деинсталлятор при этом удаляет обе папки (и `AMICON\Amiconnect`, и
`АМИКОН\Амиконнект`, инструкции 158–161), поэтому «осиротевших» ярлыков не
остаётся — дефект чисто в выборе языка.

## Причина

Условие `IntCmp $Var61 25` (равно 25 = русский) ведёт на **английские** ветки:
прыжок при равенстве оформлен наоборот, либо константа в сравнении должна быть
не 25, а 9. В коде также нет ни одного сравнения со значением 9, т.е. английская
ветка выбирается «по остаточному принципу» (`≠ 25`), что и маскировало ошибку
при беглом тестировании.

## Как исправить

Поменять ветки местами (или сравнивать с 9):

```nsis
; было: IntCmp $Var61 25 0 label_English label_English   (в EN-ветку прыгаем при RU)
; надо: IntCmp $Var61 25 label_english 0 0  →  при 25 (русский) сразу к EN-коду? нет:
IntCmp $Var61 25 0 label_english label_english   ; но тело должно быть:
;   $Var61 == 25 → русские ярлыки/русская лицензия
```

Практически: либо инвертировать две ветки ярлыков (1691–1696 ↔ 1697–1701) и
две ветки лицензии (1706 ↔ 1708), либо в `.onInit` присваивать `$Var61`
одинаковые по смыслу значения и сравнивать строго:
`$Var61 = 25` для RU и `$Var61 = 9` для EN, а проверку писать
`IntCmp $Var61 9 0 label_english label_english`.

## Как воспроизвести

1. Собрать/запустить установщик на чистой машине с русским языком (или с ключом
   `/S`, при котором язык берётся из реестра — см. BUG-06).
2. Открыть меню «Пуск»: появится папка с английским названием.
3. Открыть `%ProgramFiles%\AMICON\Amiconnect\License.txt` — текст на английском.
