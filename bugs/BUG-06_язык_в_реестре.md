# BUG-06. Выбранный язык установщика затирается при каждом запуске

* **Важность:** низкая (не ломает установку, но делает бесполезным сохранение языка
  и принудительно включает русский в silent-режиме)
* **Компонент:** установщик, `.onInit` и обработчик смены языка
* **Инструкции:** 163, 2270–2273

## Суть

Сохранённый язык установщика хранится в
`HKLM\SOFTWARE\AMICON\Amiconnect\Installer Language`, причём **двумя разными
способами**:

```
; .onInit — при каждом запуске, до диалога выбора языка:
2270  WriteRegDWORD HKLM "Software\AMICON\Amiconnect" "Installer Language" 1049
2271  ReadRegStr  $Var100 HKLM "Software\AMICON\Amiconnect" "Installer Language"
2272  StrCmp     $Var100 0 label_2274 0
2273  StrCpy     $LANGUAGE $Var100
2274  IfFlag     bit=8 …            ; (бит 8 — признак «молчаливого» режима /S)
```

```
; обработчик смены языка (вызывается при выборе языка в диалоге):
163   WriteRegStr HKLM "Software\AMICON\Amiconnect" "Installer Language" "$LANGUAGE"
```

Проблемы:

1. **Значение 1049 (русский) записывается всегда** — это литеральная константа, а не
   текущий `$LANGUAGE`. Любой ранее сохранённый выбор (1033/английский) затирается
   ещё до того, как он будет прочитан, поэтому чтение на 2271 всегда даёт «русский».
2. **Тип значения непостоянен**: `.onInit` пишет `REG_DWORD`, обработчик — `REG_SZ`.
   Обе записи читаются `ReadRegStr` (exehead умеет преобразовывать `REG_DWORD`), но
   для внешних средств (PowerShell, панель реестра, скрипты поддержки) это
   неожиданно: в одном случае `Installer Language = 0x00000419`, в другом — строка `"1049"`.
3. В результате **в молчаливом режиме (`/S`) установщик всегда русский**, независимо
   от системы и от прежнего выбора пользователя: `$LANGUAGE` берётся из заведомо
   перезаписанного значения, а диалог выбора языка в этом режиме пропускается
   (`IfFlag bit=8` → 2293).

## Последствия

* На англоязычной машине `setup.exe /S` создаёт русские ярлыки (см. также BUG-01 —
  из-за инверсии языка получится «английская» папка) и русские тексты UI;
* сохранённый выбор языка не работает (бесполезная настройка в реестре);
* внешние скрипты проверки версии/языка могут читать значение неверного типа.

## Что должно быть

```nsis
; .onInit: только читать, ничего не писать
ReadRegStr $Var100 HKLM "Software\AMICON\Amiconnect" "Installer Language"
StrCmp $Var100 "" +2 0
  StrCpy $LANGUAGE $Var100

; после завершения выбора языка (в обработчике) — писать фактический выбор, одним типом:
WriteRegStr HKLM "Software\AMICON\Amiconnect" "Installer Language" "$LANGUAGE"
```

## Как воспроизвести

1. Установить ПО, выбрав английский язык.
2. Посмотреть реестр: `HKLM\SOFTWARE\AMICON\Amiconnect\Installer Language`.
3. Запустить установщик повторно (или с `/S`) — значение снова станет
   `1049` (`REG_DWORD`), а интерфейс/ярлыки будут русскими.
